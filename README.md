# Telescopic Robot

Telescopic Robot is a toy MuJoCo/RoboVerse robot-control example for a radial
sphere with many telescoping bars.

## What it does

- Generates the robot MJCF programmatically from a configurable number of bars.
- Runs a radial-sphere locomotion demo in MuJoCo through RoboVerse/MetaSim.
- Uses an open-loop path-following controller to extend bars and roll along a
  sinusoidal path.

## Status

This is a compact custom-robot simulation example. It is not yet a full
reinforcement-learning training pipeline.
